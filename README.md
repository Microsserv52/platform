# Platform

Aplicação web que permite aos usuários comprar e vender produtos

## MKDocs

To build the documentation, you need to have Python and pip installed. Then, you can install MkDocs and the Material theme by running the following command:

```bash
pip install -r requirements.txt
```

Then, you can build the documentation by running:

```bash
mkdocs build
```

To serve the documentation locally, you can run:

```bash
mkdocs serve
```
